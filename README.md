# 📊 Sales Dashboard (Power BI)

## 📌 Project Overview
This project presents an **interactive Sales Dashboard built using Power BI** to analyze overall business performance across multiple dimensions such as **sales, profit, quantity, product, category, region, and time**.

The dashboard enables stakeholders to quickly understand key performance indicators (KPIs), identify sales trends, compare regional performance, and evaluate top-performing products for better business decision-making.

---

## 🎯 Project Objectives
- Monitor overall sales and profitability  
- Analyze monthly sales trends  
- Compare sales performance across regions and categories  
- Identify top-performing products  
- Provide an interactive and user-friendly dashboard for business insights  

---

## 🛠 Tools & Technologies Used
- **Power BI** – Dashboard development and visualization  
- **Power Query** – Data cleaning and transformation  
- **DAX** – Creation of KPIs and calculated measures  
- **Excel / CSV** – Source data  

---

## 📈 Dashboard Features
- **Monthly Sales Trend Analysis**  
- **Category-wise Sales Distribution** (Fashion, Electronics, Home)  
- **Region-wise Sales Performance** (North, South, East, West)  
- **Top Products by Sales**  
- **Interactive slicers** for Region, Category, and Product filtering  

---

## 🔍 Key Insights
- Sales show clear monthly variation, indicating seasonal demand patterns  
- Certain regions consistently outperform others in total sales  
- A small number of products contribute significantly to overall revenue  
- Balanced profit margins indicate stable pricing strategy  

---

## 📁 Dataset Used
The dashboard uses a structured sales dataset containing transaction-level information.

**Dataset Details:**
- Sales date and month  
- Product name and category  
- Region  
- Quantity sold  
- Sales amount and profit  

**Data Preparation:**
- Cleaned and transformed using **Power Query**  
- Calculated measures and KPIs created using **DAX**
